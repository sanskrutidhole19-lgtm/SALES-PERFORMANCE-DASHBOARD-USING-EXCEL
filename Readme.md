<h1 align="center">📊 Sales Performance Dashboard – Excel Project</h1>

📌 Project Overview

This project is an interactive Excel Sales Dashboard designed to analyze and visualize sales performance data using Pivot Tables, Charts, KPIs, Slicers, and Data Analysis techniques.

The dashboard helps in tracking:

* Total Sales
* Total Profit
* Product Performance
* Category-wise Sales
* Monthly Trends
* Payment Mode Analysis
* Sales Type Distribution

The project demonstrates practical Excel dashboarding skills commonly used in business intelligence and data analytics roles.

---

🛠️ Tools & Features Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* KPI Cards
* Slicers & Filters
* Conditional Formatting
* Data Cleaning
* Interactive Dashboard Design

---

📂 Dataset Information

The dataset contains transactional sales records with the following fields:

| Column Name         | Description                |
| ------------------- | -------------------------- |
| DATE                | Transaction date           |
| PRODUCT ID          | Unique product identifier  |
| PRODUCT             | Product name               |
| CATEGORY            | Product category           |
| QUANTITY            | Quantity sold              |
| SALE TYPE           | Type of sale               |
| PAYMENT MODE        | Payment method             |
| BUYING PRICE        | Product buying cost        |
| SELLING PRICE       | Product selling price      |
| Total Buying Value  | Total cost                 |
| Total Selling Value | Total revenue              |
| Day / Month / Year  | Time-based analysis fields |
